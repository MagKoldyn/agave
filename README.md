# Сердце Агавы — игровой прототип

Автономный браузерный вертикальный прототип по производственной, художественной и нарративной спецификациям.

## Запуск

```bash
npm start
```

Откройте `http://localhost:4173`. Для быстрого запуска без сервера можно также открыть `index.html` напрямую.

## Управление

- `WASD` / стрелки — движение
- `E` — взаимодействие
- `1` — семена, `2` — лейка, `3` — корзина
- `J` — журнал
- `Esc` — закрыть окно

Прогресс автоматически сохраняется в браузере после важных действий и завершения дня.

## Проверка

```bash
npm test
```
