# Сердце Агавы

Сюжетная изометрическая 2.5D игра о ферме, памяти земли и будущем Сан-Педро. Проект создаётся по производственной спецификации, нарративной и художественной библиям.

Текущий этап — первая полноценная глава вертикального среза «Корни». Это новая Godot-версия; ранний браузерный прототип удалён.

## Что уже работает

- Рисованная ферма с домом, колодцем, мастерской, рынком и акведуком.
- Управляемый персонаж, Лусия и контекстные взаимодействия.
- Четырёхнаправленная покадровая ходьба, бег и три варианта одежды героя.
- Анимированная дверь дома, течение каналов, водопады и пена.
- Активная цепочка из 12 заданий без ожидания в реальном времени.
- Расчистка, обработка почвы, посадка, полив, рост и сбор агавы.
- Поиск дневника, ремонт канала, производство сиропа и продажа.
- Смена дня, экономика, инвентарь, журнал, диалоги и сохранение.
- Завершение главы с предварительным выбором трёх сюжетных путей.

## Запуск

Требуется Godot 4.6 или новее.

```bash
godot4 --path .
```

Либо импортируйте `project.godot` через Godot Project Manager и нажмите F6/F5.

## Управление

- `WASD` / стрелки / левый стик — движение.
- `Shift` / нажатие левого стика — бег.
- `E` / `Space` / нижняя кнопка контроллера — взаимодействие.
- `1`, `2`, `3` — мотыга, семена, лейка.
- `J` — полевой журнал.
- `Esc` — закрыть окно или вернуться в меню.

## Проверка

```bash
XDG_CONFIG_HOME=/tmp/agave-config \
XDG_DATA_HOME=/tmp/agave-data \
XDG_CACHE_HOME=/tmp/agave-cache \
godot4 --headless --path . --script tests/test_game_state.gd
```
